# Monoalphabetic Substitution Cipher Cryptanalysis

This module implements a monoalphabetic substitution cipher and performs frequency, word pattern, and structural analysis to recover plaintext from ciphertext without using cryptographic libraries.

## Repository Location
`attacks/monoalphabetic_cipher_attack/`

## How to Execute
```bash
g++ -std=c++17 src/main.cpp -o attack_runner
./attack_runner
