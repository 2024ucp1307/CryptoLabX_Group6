Since this holds for every message distribution, we can choose a distribution that places all its mass on some message m. For this distribution, the probability that M equals m is equal to one. Perfect secrecy requires that for every ciphertext c, the conditional probability that M equals m given that C equals c is equal to the probability that M equals m. Since the probability that M equals m is equal to one, the conditional probability that M equals m given C equals c must also be equal to one. 

This implies that for every ciphertext c, there is only one message m that could have resulted in ciphertext c under some key. If there were two such messages m1 and m2, then the conditional probability given C equals c for at least one of them would have to be strictly less than one, contradicting perfect secrecy.

Now consider the set of keys that encrypt message m to ciphertext c. If the key space is smaller than the message space, then by the pigeonhole principle there must be some ciphertext c that can be decrypted to more than one message under different keys. But we have just shown that for perfect secrecy, each ciphertext must correspond to at most one possible plaintext message. Therefore, the number of keys must be at least as large as the number of possible messages.
