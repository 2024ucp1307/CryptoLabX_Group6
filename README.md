# CryptoLabX

## Overview

CryptoLabX is a Python-based Cryptography Toolkit developed as part of the Cryptography Laboratory course. The objective of this project is to implement various cryptographic algorithms, cryptanalysis techniques, and text analysis tools through a menu-driven command-line interface.

Currently, the project provides the basic project structure, command-line interface, logging functionality, and dataset analysis framework. Encryption and decryption algorithms will be added in future assignments.

---

## Features

- Menu-driven Command Line Interface
- Encrypt Module (Coming Soon)
