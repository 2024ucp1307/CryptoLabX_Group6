# Cryptocurrency Wallet - Lab Assignment 3

## 1. Project Overview

This project is developed as part of **Lab Assignment 3** for the Cyber Security laboratory.

The assigned application for **Group 6** is a **Cryptocurrency Wallet**.

The application is a small console-based C++ program that simulates basic cryptocurrency wallet operations. It is developed only for educational and security testing purposes.

The application does **not** implement real cryptocurrency, blockchain technology, or cryptographic operations.

---

## 2. Application Objectives

The main objectives of this project are:

- Implement the basic functionality of a cryptocurrency wallet.
- Demonstrate common software security vulnerabilities.
- Analyze the source code using a Static Application Security Testing (SAST) tool.
- Identify vulnerabilities using Semgrep.
- Test the vulnerabilities manually.
- Fix the identified vulnerabilities.
- Perform SAST analysis again after fixing the vulnerabilities.
- Compare the vulnerable and secure versions.
